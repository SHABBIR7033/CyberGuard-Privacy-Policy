# Extension Privacy Center

Permanent static privacy-policy site for browser extensions.

## Pages
- `/` — Privacy Center
- `/cyberguard-ai/` — CyberGuard AI
- `/focuslens/` — FocusLens

## GitHub Pages
Publish from the `main` branch and the repository root. The URLs will be:

`https://YOUR-USERNAME.github.io/extension-privacy-center/`

Add a new folder and `index.html` for each future extension.
